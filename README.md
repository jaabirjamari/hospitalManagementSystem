# Hospital Management System

A Java/Spring Boot REST API for managing patient and doctor records.

## Tech
Java, Spring Boot, Spring Data JPA, JUnit, Mockito, GitHub Actions

## Structure
Controller, service, repository, and model layers for Patients and Doctors.

## Endpoints
- `/api/patients` and `/api/doctors`: GET by id, POST, PUT, DELETE
